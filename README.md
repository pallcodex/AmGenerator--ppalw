# ⚡ AmGenerator

> **AmGenerator** adalah tools web modern berbasis API untuk membuka semua fitur premium di Alight Motion secara gratis dan instan.

---

## 🚀 Fitur Utama

- **100% Gratis & Tanpa Iklan** — Akses fitur tanpa dipungut biaya dan bebas gangguan.
- **Ultra-Fast API** — Proses verifikasi cepat yang ditenagai langsung oleh API Lann.
- **Unlock All Features** — Buka akses preset, ekspor tanpa watermark, dan fitur Alight Motion Pro lainnya.
- **Neo-Brutalist UI** — Tampilan antarmuka yang unik, responsif, dan interaktif dilengkapi *background music*.

---

## 🛠️ Cara Penggunaan

1. **Langkah 1: Kirim Auth Link**
   * Masukkan email aktif yang terdaftar di akun Alight Motion Anda.
   * *(Opsional)* Isi Custom Order ID jika ingin kustomisasi.
   * Klik **Kirim Link**.

2. **Langkah 2: Cek Email**
   * Buka Inbox atau folder Spam di email Anda.
   * Cari pesan dari Alight Creative, lalu salin **Access Key** / Link Verifikasinya.

3. **Langkah 3: Aktivasi**
   * Tempel link verifikasi ke kolom Langkah 2 di website.
   * Klik **Aktifkan Premium** dan selesai!
